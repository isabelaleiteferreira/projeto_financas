# Finanças Pessoais

Projeto de gestão financeira pessoal com engenharia de dados.

Os dados são sincronizados via Open Finance (Meu Pluggy), transformados em camadas
medalhão (bronze, silver e gold) com dbt, orquestrados com Airflow e apresentados em
um app web Streamlit.
